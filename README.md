# AI-Based Resume Screening and Candidate Recommendation System

This project uses Natural Language Processing (NLP) techniques to automatically analyze resumes and rank candidates according to job requirements.

## Technologies
- Python
- Streamlit
- NLTK
- TF-IDF
- Cosine Similarity
- Scikit-Learn

## Dataset
Resume Dataset from Kaggle

## Features
- Resume Parsing
- Skill Matching
- Candidate Ranking
- Graphical Analysis

## Run

pip install -r requirements.txt

streamlit run app.py
